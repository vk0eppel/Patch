# Panel visibility defaults: peers always on, macros conditional

The Peers panel defaults to visible because situational awareness of who is on the network matters from the moment an Operator opens the app — the panel is compact enough that the space cost is acceptable. The Macros panel defaults to visible only when macros are configured; an empty macros panel on first install is dead space and signals nothing useful. A third state (collapsed/compact) was considered for the Peers panel but rejected — the panel is already compact, adding a third toggle state adds complexity without value.
